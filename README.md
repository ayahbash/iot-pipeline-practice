# iot pipeline practice
practice repo for building and testing parts of an iot data pipeline for an internship.

## structure:
```
├── py_xml/
│   └── python scripts for xml/witsml parsing and data extraction
├── grafana/
│   └── dashboards and configuration files for time-series visualization
├── simulator/
│   └── python script to generate realistic test data for dashboards
├── mqtt/
│   └── publisher.py & subscriber.py for mqtt data communication
```
- dashboards are reusable templates
